# H-6｜地雷區

規則一句話：兩個人在**同一張藏著地雷的地圖**上每回合**同時**選一格往前走，某一排**先踏上的人拿全額、後到的拿一半**，踩到雷就失去還沒存的分，可以停下來存分；**你踩出來的安全格與雷，對方也能用**。

局長：14 回合，每回合約 200 tick，共約 2800 tick，**約 47 秒**。

♥ 紅心 6。**設計文件，尚未實作、未量測。**

類型：**互相牽制型**（共用地圖、共用「已揭露的資訊」）＋**互相讀取型**（同時出手，要預測對方是領頭還是跟隨）。

## SPEC 第 9 節的原始方向、為什麼改、改成什麼

- **原始方向：** 「走得越遠分越高、地雷越密，可以回頭存分。」
- **為什麼改：** 各走各的，AI 只是旁人。
- **改成什麼：** 同一張地雷圖。**踩雷與走過的安全格都變成公開資訊**，所以領頭的人在替對方付學費。為了讓領頭不是白白吃虧，**先到的人拿全額，後到的拿一半**。結果是一個「領頭拿高分但冒險」對「跟隨拿半分但免費」的賽局：**AI 領頭，你就跟；AI 等，你要決定要不要先冒險；AI 存分，你就知道要追多少。**

## 規則

- 地圖：4 欄 × 6 排。每一排藏的地雷數：`MINES = [1, 1, 2, 2, 3, 3]`（越遠越密），位置由種子決定，**兩人看到同一張圖**。
- 每排的獎勵 `R = [1, 2, 3, 5, 8, 12]`：第 `r` 排**第一個**安全踏上去的人拿 `R[r]`，**後到的人**拿 `ceil(R[r] / 2)`；**同一回合同時到的兩人都拿全額**。獎勵進「手上的分」（`carry`），還沒入袋。
- 每個人站在某一排（0 是出發點）。每回合兩邊**同時**選一個動作（選了不能改）：
  - **← ↑ → ↓**：踏上下一排（現在在 `p`，就是第 `p + 1` 排）的第 1、2、3、4 欄。
  - **a：存分**：`carry` 全部進總分，`carry = 0`，位置不動。
  - **b：等一回合**。
- 結算（兩邊同時）：踏上的格子如果是雷：**爆炸**，`carry = 0`、位置回到 0，那一格變成公開的「雷」。不是雷：位置前進、`carry` 加獎勵（先到／後到），那一格變成公開的「安全」。**已經公開的安全格，踏上去沒有風險**（但仍照先到／後到算獎勵，而且同一排你只會領一次）。
- 14 回合結束，**只算總分**（手上沒存的分作廢），高的贏，一樣多平手。到第 6 排之後沒有下一排，只能存分或等。
- 每個決定等 300 tick，超時自動選 b（等）。每回合開頭兩邊都有 45 tick 準備（輸入忽略）。

## 參數

常數：`COLS = 4`、`ROWS = 6`、`MINES = [1,1,2,2,3,3]`、`R = [1,2,3,5,8,12]`、`ROUNDS = 14`、`LOCK_TICKS = 2`、`RESULT_TICKS = 30`。

## 資訊限制

- 地雷圖在 state 裡（`mines`），**不公開**；公開的只有 `known`（每格：0 不知道、1 安全、2 雷），每排的雷數是規則（畫面直接畫出來）。
- **`evaluate`、`actions` 不可以讀 `mines`**，也不可以讀對方這回合的 `pending`。AI 只用 `known` 與「每排幾顆雷」算每格的安全機率。測試：只有 `mines` 不同（但 `known` 一樣、AI 的位置一樣）的兩個狀態，AI 側 `evaluate` 與 `actions` 相等；黑箱版：四個性格在深度 1、3、6 下 `decide` 相同。
- 4.4：畫面**不顯示**每格的機率，只顯示已知的格子與每排的雷數；玩家自己算。

## 預設性格與 baseLevel

搜尋型（`pathfinder`），`baseLevel = 2`，`symmetric: true`，`luckHeavy: true`。

## 操作

方向鍵選欄，a 存分，b 等。

## state

`H6State`：`tick`、`maxTicks`、`over`、`winner`；`round`（0 到 13）；`phase`（`'prep' | 'choose' | 'locked' | 'resolve'`）、`wait`、`idle`；`mines`（隱藏）；`known`（6×4）；`claimed`：每排 `[bool, bool]`（誰已領過）；`row`：兩邊的排數；`carry`、`totals`；`pending`：`[Move|null, Move|null]`；**`last`：這回合的結果（只在 `resolve`，30 tick 後才入帳進 `known`、`carry`，`evaluate` 不讀）**；`history`：每回合兩邊的動作類型（`lead` 領頭＝踏上沒被公開的格子、`follow` 跟隨＝踏上公開安全格、`wait`、`bank`），最多 14 筆，公開；`salt`、`rng`。

## 動作與評估

- `actions(state, side)`：`choose` 階段、自己還沒出手：`[b 等, ← ↑ → ↓ 中現在合法的, a]`（沒東西可存時沒有 a；已到第 6 排沒有方向）。**等排第一**。
- 令 `safe(r, c)`：該格已知安全是 1，已知雷是 0，否則 `（該排雷數 − 已揭露的雷） / 該排未揭露的格子數` 的補數（均勻、公開）。
- `evaluate(state, side)`：
  - 結束：`gain = 分差 ± 1000`。
  - `locked` 及更早：`gain = 分差 + 0.5 · carry + HABIT · [反射規則]`，`HABIT = 0.01`。**反射規則：往前走，優先走已知安全的格，沒有就走 `safe` 最大的；`carry ≥ 5` 就存分；不等。**
  - `resolve`（模擬走到結果）：用對手動作的**預測分佈** `Q`（`lead`／`follow`／`wait`／`bank`，由 `history` 最近 `W = 4` 回合與對方的 `carry`、排數算：`leadRate = (領頭次數 + 1) / (回合數 + 3)`）展開：我走格子 `x` 的期望 ＝ `safe(x) · [獎勵(先到 或 同時 或 後到 依 Q 算) + 未來]` − `(1 − safe(x)) · (carry + 回到起點的重走成本)`。**不讀 `last`、`mines`。**
  - `danger`：這一步踩雷的機率 `1 − safe(x)`，其他是 0。

## 結算流程與等級曲線（準則 5.1）

**3 步：** 出手（`locked`，`wait = 2`）→ 鎖定第二步 → 結算（`resolve`，`wait = 30`）→ 入帳進 `known`。
- **深度 1 到 2（等級 1 到 3）：** 只有反射規則：「往前走、`carry ≥ 5` 就存、從不等」。**它是個永遠領頭的莽夫**，不理會對手；你可以永遠跟在它後面撿一半的分，而且踩雷的是它。
- **深度 ≥ 3（等級 4 以上）：** `evaluate` 看得到「對方會不會領頭」的預測，所以會**等**：你在第 4 排前面不動，它也不動；你領頭，它就踏上你揭露的安全格。
- **等級 10：** 加上快速反應與每 tick 重新決定，並且讀 `leadRate`：你習慣領頭，它就跟；你習慣等，它在獎勵 ≥ 8 的排自己上（因為等下去 14 回合會用完）。

## 為什麼跟 AI 互動起來好玩

**AI 的哪一個選擇會改變你的最好做法？** 領頭（它替你揭露一格，你可以免費跟）、等（你要決定是不是先冒險）、存分（你知道要追多少）、踩雷（那一排的雷位置公開）。四個動作都改變你的最好動作，不是只有一個。

**你怎麼騙它：** 前幾回合都領頭、都不等，讓它學到「你會領」，之後它會習慣跟，你在第 5、6 排**突然等**，它也在等嗎？它的 `leadRate` 預測錯了，雙方一起空轉，最後 3 回合時間不夠，等得起的那一邊吃虧。你也可以假存分：在第 3 排存分，它以為你停手，領頭去搶第 4 排的全額，你再跟著撿半額加上它揭露的安全格。

**四種性格**（指紋：領頭比例、踩雷次數、存分時的平均 `carry`、等的次數）：

| 性格 | 怎麼打 | 利用它 |
|---|---|---|
| 搜尋型 | 預測你，等你領頭 | 你要先用「假存分」逼它出手 |
| 精準型 | 只走 `safe ≥ 0.7`（幾乎只跟隨），`carry ≥ 3` 就存 | 它領頭很少；你領頭它跟，你只拿全額，但它永遠不會爆 |
| 貪心型 | 一步看：往獎勵最大的排衝，不看安全 | 踩雷最多、永遠領頭：你只跟 |
| 賭徒型 | 落後越多越敢踩 25% 安全的格 | 領先時你就等，它會自己撞 |

## 我做的決定

1. **先到全額、後到半額。** 理由：沒有這個，跟隨永遠比領頭好，沒人領頭；有了它，領頭有價值但有風險。比例（1/2）沒有量，是起始值。
2. **同時到算都是全額。** 理由：同時出手時不應該有隱性的先後；也讓「同一回合兩人都冒險」的結果對稱。
3. **踩雷：失去 `carry` 並回到起點，不扣總分。** 理由：重走的代價是時間（回合數），不是分數，這讓「存分」有意義（存了的不怕）。
4. **14 回合固定，最後只算總分。** 理由：讓「等」有時間成本，避免兩邊永遠僵持。
5. **同一排只領一次獎勵。** 理由：重走已知路線不應該重複拿獎勵。
6. **按鍵：方向鍵＝欄。** 理由：四個欄剛好四個方向鍵，a／b 留給存分與等；不需要任何加鍵。
7. **預設性格用搜尋型。** 理由同 H-Q。

## 我的疑慮

1. **規則數字很多（獎勵表、雷數表、先到後到、回合數）。** 一句話講得完，但第一次玩要三十秒才懂。畫面要把「已揭露的格子」與「這排先到後到各幾分」畫清楚。
2. 它比較像**消耗戰**，不太是「讀心」：AI 的「等」是否有趣，要看實作後的 14 回合是不是常常雙方僵持；如果是，把 `ROUNDS` 縮短或讓「等」有 1 分的成本。
